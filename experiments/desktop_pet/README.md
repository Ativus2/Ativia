# Ativia 轻量桌宠试验品

透明无边框 PySide6 6.11.2 QWidget，默认 160 逻辑像素，可选 140/180；当前为用户提供的透明 PNG 像素角色。绑定一个明确的 native-voice 实例，固定 **gpt-realtime-2.1-mini / marin / 官方 Agents SDK 0.18.0 / WebRTC**。不调用 GPT-SoVITS，不修改原人格、不做旧应用迁移。

## 启动 / 使用 / 退出

1. 原生语音实验：在仓库根目录双击 **start-native-voice-experiment.bat**。日常入口 `start.bat` / 兼容别名 `start-desktop-pet.bat` 已复用同一个 PetWindow，连接根目录日常后台。本实验首次只显示桌宠和本机控制服务，没有浏览器收音、系统声音或截图。
2. 悬停显示快捷栏，点“开始”；首次打开专用 Edge 页后，点“开始会话 / 授权”，允许麦克风与播放。连接期间声音发往 OpenAI，并使用 AI 合成声音回答。没有绕过浏览器权限。
3. 完全暂停按钮等待采集和会话关闭后才显示“已完全暂停”；红点/“收音”文字和托盘仍清楚标记实际收音。停止当前回答只打断本轮。恢复是明确鼠标操作，不监听唤醒口令。
4. 拖动人物可记住位置，允许进入任务栏区域、继续下移将下半身藏到屏幕下方；至少保留 64 逻辑像素可供拖回。重启保留位置，显示器变化后按完整屏幕边界校正。悬浮按钮和字幕仍留在可用工作区。点击托盘或“显示桌宠”可将整个角色找回任务栏上方。右键可改尺寸、置顶、静态显示和字幕。隐藏桌宠**仍继续运行助手**，托盘显示实例和收音状态。
5. **start-native-voice-panel.bat** 单独打开语音调试页；若桌宠正在运行则复用已有实例/浏览器。该页面与桌宠共享唯一 capture owner，不能各自启动一套收音。旧 experiments/native_voice/start.bat 仍能独立启动，但不得与桌宠同时抢占 9884 端口。
6. 右键或托盘“退出本次助手”，或根目录 **stop-native-voice-experiment.bat**：先请求结束会话，再清理本启动器的专用浏览器及 Python 服务。`stop-desktop-pet.bat` 现在停止日常实例。启动器用 Windows Job Object 约束自有进程树，不终止其他浏览器、9883 或其他实例的本地音色服务。

已绑定能力：开始、完全暂停、恢复、打断、真实麦克风开关、打开同一会话、字幕、拖动/尺寸/置顶、隐藏/托盘、退出。自动观察屏幕与系统音频菜单禁用并标明“当前实验未接入”。没有创建新功能补全菜单。

## 状态与音频边界

- 角色显示未连接、待机、收音、思考、说话、正在暂停、已暂停及错误/失联。信任来自语音页的实际状态，命令发出/accepted 不等于完成。
- 暂停先关闭服务端新请求准入，再释放浏览器音轨、WebRTC、播放元素。迟到回调跨 epoch 失效，未处理字幕清空，取消不 fallback/retry。已发送请求不能撤回，音频设备尾缓冲不能声称立即归零。
- 恢复重新建立连接；已有完成回答在本页内存保留，但完整音频上下文**不恢复**。麦克风本来关闭则恢复保持关闭。
- 字幕最长显示 76 字，点击气泡打开完整会话。暂停/隐藏不会补播积压内容。字幕使用纯文本，不执行模型返回的标记。
- 页面与桌宠通过少量 WebSocket 命令和确认状态通讯。随机本机访问 key、同源校验、单一 lease、generation 阻止重复收音和暂停绕行。API key 只在服务读取，专用浏览器环境去掉相关长期密钥变量。
- 失去本机控制连接后页面主动清理音频；没有自动重连或自动恢复。首次权限弹窗仍在等待时保持“正在暂停”，等浏览器返回后释放；也可退出本次自有浏览器。
- 说话动画由非零 WebRTC 入站音频能量 + 音频元素正在前进的时钟驱动；字幕不会触发动画。并非声卡扬声器声学探头，外放真实停止、回声、双讲仍需真人。

## 环境、资源及素材

复用 `experiments/realtime_prototype/.venv` 中的 Python 和现有 PySide6/QtSvg/QtWebSockets，没有安装第二套 Qt、QtWebEngine、Electron/Tauri、全局键盘钩子或游戏覆盖层。构建浏览器脚本仍使用 native_voice/build.bat。node_modules、浏览器 profile、运行 key、个人反馈和位置设置均被 gitignore。

Qt 绘制为轻量 2D，动画定时器上限 10Hz，只有思考/说话且可见时启用；暂停、隐藏和静态模式停止不必要动画。不为独占全屏游戏强制注入，可能需要窗口化/无边框模式。

当前角色在 **assets/ativia-pixel.png**，由用户供图并提取透明背景，保持静态表情，通过状态条显示运行状态。原始占位 **assets/ativia.svg** 保留作资源不可读时的后备。以后可替换透明 PNG 并重启，尺寸等比适应、点击轮廓自动更新，详见 assets/README.md。程序参考 Qt 官方窗口 API，未复制 BongoCat 代码、素材或全局输入行为。

资源实测详见 docs/desktop-pet-trial：UI 单独运行约 58–62 MiB；动画约 9.2 次绘制/秒，暂停/隐藏 0 次持续绘制。短窗口 CPU 读数不等于长期性能保证，首次暂停样本 16.87% 单核 CPU 的瞬时波动未在复测重现，原始记录保留。整卡 GPU 数据包含正在运行的游戏，不能归因于桌宠；浏览器和服务内存另计。

## 验收与当前限制

当前代码和按钮已完成真实 Qt → 本机服务 → 语音页面控制接线。自动联调用的是**离线 SDK 替身和生成的测试音轨**，测试服务 session-limit=0，外部 OpenAI 请求拦截。生产版没有引入替身；实际 Edge 生产页已验证打开不收音。

此前同组任务已用完 3 次付费会话，所以本轮新增 **0 次**，未再次进行“桌宠 + 云端回答”试听。此前原生路线模型权限/音频验证记录保留，不能拿它冒充新桌宠云端联调。外放、误打断、漏字、完整聊天质量、声学停止延迟均待真人验收，不满足完整迁移放行条件。

简短真人步骤：暂停其它实例 → 桌宠开始并在页面授权 → 短问一句 → 她说话时插话 → 桌宠完全暂停 → 继续说话应无新回答 → 恢复问新问题 → 退出并检查麦克风指示消失。后续由用户主动试听会产生模型费用；不开启自动测试。页面“真人测试与反馈”保存主动填写的反馈到 native_voice/logs/feedback.jsonl，不保存原始音频或私人对话。
