# 外语口语练习

先按项目 README 安装完整依赖并配置自己的 API，再运行 `python -m language_practice.launch`。

1. 选择语言、难度和练习话题。可以从韩语“休闲活动及其优缺点”或“推荐一首歌曲”开始。
2. 填写想在对话中使用的个人背景，点击开始。练习背景会用于生成提问和参考回答。
3. 阅读问题和参考字幕。参考回答只显示，不会播放；问题朗读可以开关。
4. 开始录音，自己回答或照着字幕练习。停止后检查识别内容，必要时修改，然后提交。
5. Ativia 根据提交内容继续追问。遇到难句可以简化参考回答，也可以隐藏中文提高难度。

计时用于帮助练习五分钟或更长的对话，没有五分钟自动停止。单次录音最多 90 秒。无需麦克风时可以直接输入回答。

练习需要联网，文本和主动提交的录音会发往所配置的服务。密钥与个人练习设置保存在本机，不包含在 GitHub 快照中。

本次功能已完成离线测试，以及经授权的虚构背景文字、合成韩语音频接口测试。真人麦克风、扬声器和完整五分钟对话尚未由真人验收。
